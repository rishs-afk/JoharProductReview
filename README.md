# The Johar Client Preview Site

Open `index.html` locally, or publish this folder with GitHub Pages.

This folder is self-contained. Preview images are optimized copies in `assets/images/` and all image references are relative paths.

Recommended GitHub Pages setup:
1. Create a new repository.
2. Add the contents of this `client_preview_site` folder.
3. Enable GitHub Pages from the repository root.

Important: this is for preview/review only. Shopify upload still needs final client approval plus Shopify image hosting/upload.
